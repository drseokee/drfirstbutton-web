# 닥터첫단추 로고

흰 가운 실루엣 + 금색 첫 단추 (2026-11-26 확정). 유튜브·블로그 프로필은 기존 일러스트(가운의 금색 첫 단추를 끼우는 손)를 그대로 쓰고, 이 마크는 사이트·인쇄 등 그 밖의 곳에 쓴다. 두 그림이 '금색 첫 단추'로 이어진다.

| 파일 | 쓰는 곳 |
|---|---|
| logo.svg | 흰 바탕 (가운 먹색 #111) |
| logo-on-dark.svg | 검은 바탕 (가운 #F2F2F0, 그대로 흰 가운이 됨) |
| ../../site/favicon.svg | 브라우저 탭 (다크 모드에서 자동으로 밝은 가운) |
| ../../site/apple-touch-icon.png | 아이폰 홈 화면 (검은 바탕 + 흰 가운) |

규칙
- 색은 두 가지뿐: 가운(먹색 또는 밝은 회백색) + 단추 금색 #B08A3E. 금색은 단추에만, 광택·그러데이션·반짝임 없이 단색.
- 단추 위치와 크기를 바꾸지 않는다 (64 격자에서 중심 32,35 / 반지름 7).
- 마크 안에 글자를 넣지 않는다. 워드마크 '닥터첫단추'는 Pretendard 700으로 마크 오른쪽에.
- 최소 크기 16px. 둘레 여백은 마크 폭의 1/8 이상.
