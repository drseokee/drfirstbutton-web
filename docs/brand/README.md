규칙
- 작은 자리(48px 이하)에는 전체 그림 대신 손+금색 단추 크롭을 쓴다. 전체 그림은 작으면 안 읽힌다.
- 흰 화면에서는 원형 둘레에 1px 선(#E4E4E1)을 둘러 흰 가운이 배경에 묻히지 않게 한다.
- 그림 위에 글자·효과를 얹지 않는다.
